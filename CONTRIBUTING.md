# Contributing to PRISM 9

Thank you for contributing to PRISM 9!

## Workflow Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Ensure WASM compiles cleanly (`npm run build:wasm`).
3. Verify test suite passes (`npm run test`).
4. Run static analysis (`npm run lint`).
5. Open a Pull Request detailing your changes.
